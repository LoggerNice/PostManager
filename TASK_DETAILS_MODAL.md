# Модальное окно деталей задачи

## Описание
Реализовано модальное окно для отображения деталей задачи с интегрированным чатом комментариев, аналогичное интерфейсу на изображении.

## Функциональность

### Основные возможности:
1. **Просмотр деталей задачи** - отображение всей информации о задаче
2. **Чат комментариев** - возможность оставлять и просматривать комментарии
3. **Активность** - лента активности по задаче
4. **Редактирование статуса** - возможность изменить статус задачи прямо в модальном окне

### Структура интерфейса:

#### Левая панель - Детали задачи:
- Название задачи
- Информация о создании
- Статус (с возможностью редактирования)
- Приоритет
- Срок выполнения
- Теги
- Исполнители
- Описание задачи

#### Правая панель - Активность и комментарии:
- Вкладки: Активность, Моя работа, Назначенные, Комментарии
- Чат комментариев с возможностью добавления новых
- Лента активности с группировкой по датам

### Как использовать:

1. **Открытие модального окна**: Кликните на любую задачу в доске задач
2. **Добавление комментария**: 
   - Перейдите на вкладку "Комментарии"
   - Введите текст в поле ввода
   - Нажмите Enter или кнопку отправки
3. **Изменение статуса**:
   - В левой панели найдите поле "Статус"
   - Нажмите на иконку редактирования
   - Выберите новый статус из выпадающего списка
4. **Просмотр активности**: Перейдите на вкладку "Активность"

## Техническая реализация

### Новые компоненты:
- `TaskDetailsModal.tsx` - основное модальное окно
- `TaskActivity.tsx` - компонент отображения активности
- `comment.types.ts` - типы для комментариев
- `comment.api.ts` - API для работы с комментариями

### Обновленные компоненты:
- `TaskCard.tsx` - добавлена возможность открытия модального окна
- `api.ts` - добавлены теги для комментариев

### Backend API:
- Обновлен `commentController.ts` для поддержки фильтрации по taskId
- Добавлена поддержка включения данных автора комментария

## Интеграция с существующей системой

### Авторизация:
- Комментарии привязываются к авторизованному пользователю
- Отображается информация об авторе комментария

### Уведомления:
- Все участники проекта видят комментарии в реальном времени
- Поддержка RTK Query для автоматического обновления данных

### Стилизация:
- Использованы существующие компоненты UI
- Адаптивный дизайн
- Темная тема для карточек задач
