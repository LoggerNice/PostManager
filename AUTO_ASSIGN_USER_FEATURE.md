# Автоматическое добавление пользователя в участники

## Описание
При создании проекта или задачи текущий пользователь автоматически добавляется в список участников/исполнителей.

## Изменения

### 1. Компонент создания проекта (`postmanager-frontend/src/app/test/Test.tsx`)
- Добавлен импорт `useAuth` для получения информации о текущем пользователе
- Добавлен `useEffect` для автоматического добавления текущего пользователя в список участников
- Добавлена проверка в `onSubmit` для гарантии включения текущего пользователя
- Добавлено предупреждение, если текущий пользователь не найден

### 2. Компонент создания задачи (`postmanager-frontend/src/components/projectComponents/task/TaskModal.tsx`)
- Добавлен импорт `useAuth` для получения информации о текущем пользователе
- Добавлен `useEffect` для автоматического добавления текущего пользователя в список исполнителей
- Добавлено предупреждение, если текущий пользователь не найден

### 3. Основная страница проекта (`postmanager-frontend/src/app/projects/[id]/page.tsx`)
- Добавлен импорт `getCookie` для получения ID пользователя из cookies
- Обновлена функция `handleCreateTask` для автоматического добавления текущего пользователя в список исполнителей

## Логика работы

### Для проектов:
1. При загрузке формы создания проекта автоматически добавляется текущий пользователь в список участников
2. При отправке формы дополнительно проверяется наличие текущего пользователя в списке
3. Если текущий пользователь не найден, показывается предупреждение

### Для задач:
1. При открытии модального окна создания задачи автоматически добавляется текущий пользователь в список исполнителей
2. При отправке формы через `handleCreateTask` дополнительно проверяется наличие текущего пользователя
3. Если текущий пользователь не найден, показывается предупреждение

## Безопасность
- Все изменения происходят только на стороне frontend
- Пользователь может вручную удалить себя из списка участников/исполнителей
- Система не блокирует создание проекта/задачи, если текущий пользователь не определен

## Тестирование
1. Создайте новый проект - текущий пользователь должен автоматически появиться в списке участников
2. Создайте новую задачу - текущий пользователь должен автоматически появиться в списке исполнителей
3. Попробуйте удалить себя из списка и создать проект/задачу - система должна автоматически добавить вас обратно
