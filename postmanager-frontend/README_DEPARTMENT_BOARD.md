# Доска задач отдела

## Описание

В PostManager добавлена новая функциональность - **Доска задач отдела** на странице "Мой отдел". Эта функция позволяет начальникам отделов и администраторам управлять задачами сотрудников своего отдела в удобном формате канбан-доски.

## Функциональность

### Вкладки

Страница "Мой отдел" теперь содержит две вкладки:

1. **Обзор** (📊) - существующая функциональность:
   - Диаграмма Ганта задач отдела
   - Статистика по статусам задач
   - Статистика по сотрудникам отдела
   - Навигация по неделям

2. **Доска** (📋) - новая функциональность:
   - Канбан-доска с колонками по статусам задач
   - Фильтрация задач по различным критериям
   - Просмотр всех задач отдела в одном месте

### Колонки доски

Доска содержит 4 колонки:
- **К выполнению** - задачи со статусом TODO
- **В процессе** - задачи со статусом IN_PROGRESS
- **Согласование** - задачи со статусом PROBLEM
- **Выполнено** - задачи со статусом COMPLETED

### Фильтры

Доска поддерживает фильтрацию по:
- Поиск по названию задачи
- Приоритет задачи (Низкий, Средний, Высокий)
- Исполнитель задачи
- Период (дата начала и окончания)

## Техническая реализация

### Компоненты

- `MyDepartment.tsx` - основной компонент с табами
- `DepartmentTasksBoard.tsx` - компонент доски задач отдела

### Используемые существующие компоненты

- `TasksTab` - для отображения канбан-доски
- `TasksFilter` - для фильтрации задач
- `Column` - для отображения колонок
- `Task` - для отображения отдельных задач

### Логика фильтрации

Компонент автоматически:
1. Определяет отдел текущего пользователя
2. Фильтрует задачи, назначенные сотрудникам отдела
3. Группирует задачи по статусам
4. Применяет пользовательские фильтры

## Доступность

Функция доступна только для пользователей с ролями:
- `ADMIN` - администраторы системы
- `MANAGER` - начальники отделов

## Планы развития

В будущих версиях планируется добавить:
- Создание новых задач
- Редактирование существующих задач
- Перемещение задач между колонками
- Удаление задач
- Переименование колонок
- Drag & Drop функциональность

## Использование

1. Перейдите в раздел "Мой отдел" в боковом меню
2. Переключитесь на вкладку "Доска"
3. Используйте фильтры для поиска нужных задач
4. Просматривайте задачи по статусам в соответствующих колонках
