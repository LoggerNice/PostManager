# Звуковые уведомления

## Описание

В проекте реализована система звуковых уведомлений для различных действий с задачами.

## Звуковые файлы

Для работы звуковых уведомлений необходимо добавить следующие файлы в папку `public/`:

### 1. meet-message-sound-1.mp3
- **Назначение**: Звук создания новой задачи и комментариев
- **Когда воспроизводится**: 
  - При успешном создании задачи
  - При добавлении комментария к задаче
- **Источник**: Можно скачать с https://notificationsounds.com/ или использовать любой короткий звук

### 2. cena_notification.mp3
- **Назначение**: Звук выполнения задачи
- **Когда воспроизводится**: При перемещении задачи в статус "Выполнено"
- **Источник**: Можно скачать с https://notificationsounds.com/ или использовать любой короткий звук

## Установка звуковых файлов

1. Скачайте или создайте звуковые файлы в формате MP3
2. Поместите файлы в папку `postmanager-frontend/public/`
3. Убедитесь, что имена файлов точно соответствуют:
   - `meet-message-sound-1.mp3`
   - `cena_notification.mp3`

## Функциональность

### Создание задачи
- **Звук**: `meet-message-sound-1.mp3`
- **Уведомление**: "Задача 'Название' успешно создана! 🎉"
- **Стиль**: Зеленый фон с белым текстом

### Добавление комментария
- **Звук**: `meet-message-sound-1.mp3`
- **Уведомление**: "Комментарий успешно добавлен! 💬"
- **Стиль**: Синий фон с белым текстом

### Выполнение задачи
- **Звук**: `cena_notification.mp3`
- **Уведомление**: "Задача 'Название' выполнена! 🎉"
- **Стиль**: Темно-зеленый фон с белым текстом и иконкой трофея

### Перемещение задачи
- **Звук**: Без звука
- **Уведомление**: "Задача 'Название' перемещена в 'Название колонки'"
- **Стиль**: Стандартное уведомление

## Техническая реализация

### Функции воспроизведения звука
```typescript
// Воспроизведение звука создания задачи
const playTaskCreatedSound = () => {
  const audio = new Audio('/meet-message-sound-1.mp3');
  audio.volume = 0.5;
  audio.play();
};

// Воспроизведение звука создания комментария
const playCommentCreatedSound = () => {
  const audio = new Audio('/meet-message-sound-1.mp3');
  audio.volume = 0.5;
  audio.play();
};

// Воспроизведение звука выполнения задачи
const playTaskCompletedSound = () => {
  const audio = new Audio('/cena_notification.mp3');
  audio.volume = 0.5;
  audio.play();
};
```

### Обработка ошибок
- При отсутствии звуковых файлов ошибки логируются в консоль
- Приложение продолжает работать без звука
- Уведомления отображаются независимо от звука

## Рекомендации по звуковым файлам

### meet-message-sound-1.mp3
- **Длительность**: 0.5-1 секунда
- **Тон**: Приятный, не раздражающий
- **Громкость**: Умеренная
- **Примеры**: Звук уведомления из Google Meet, Microsoft Teams

### cena_notification.mp3
- **Длительность**: 1-2 секунды
- **Тон**: Торжественный, праздничный
- **Громкость**: Умеренная
- **Примеры**: Звук достижения, победы, завершения

## Отладка

Если звук не воспроизводится:

1. Проверьте наличие файлов в папке `public/`
2. Проверьте правильность имен файлов
3. Откройте консоль браузера для просмотра ошибок
4. Убедитесь, что браузер поддерживает воспроизведение аудио
5. Проверьте настройки звука в браузере и системе
