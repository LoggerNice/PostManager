# Компоненты диаграммы Ганта

Диаграмма Ганта была разбита на несколько переиспользуемых компонентов для улучшения читаемости и поддерживаемости кода.

## 🚀 Новые возможности

- **Автоматическая ширина** - диаграмма автоматически адаптируется к ширине родительского контейнера
- **Responsive дизайн** - корректное отображение на всех размерах экрана
- **Адаптивные отступы** - правый отступ автоматически рассчитывается как 5% от ширины (минимум 20px)
- **ResizeObserver** - точное отслеживание изменений размера контейнера
- **Надежное измерение** - множественные стратегии измерения ширины для корректной работы после перезагрузки страницы
- **Отслеживание видимости** - автоматическое обновление размеров при возврате на страницу
- **Пустые столбцы** - добавлены столбцы для воскресенья и субботы для лучшего понимания сроков выполнения задач
- **Индикаторы переноса** - пунктирные линии показывают задачи, выходящие за пределы рабочей недели

## Структура файлов

### Основные компоненты

- **`GanttChart.tsx`** - Главный компонент диаграммы, который объединяет все остальные компоненты
- **`DepartmentTasksGanttChart.tsx`** - Обертка для обратной совместимости, теперь просто вызывает `GanttChart`

### Вспомогательные компоненты

- **`TimelineHeader.tsx`** - Заголовок временной шкалы с числами месяца, днями недели и вертикальными линиями сетки
- **`UserRow.tsx`** - Строка пользователя с его задачами
- **`TaskBar.tsx`** - Отдельная полоса задачи с названием и стилизацией
- **`GanttLegend.tsx`** - Легенда статусов задач

### Хуки

- **`useGanttData.ts`** - Обработка и группировка данных задач для диаграммы
- **`useGanttDimensions.ts`** - Управление размерами и адаптивностью диаграммы

### Утилиты

- **`ganttUtils.ts`** - Функции для вычисления позиций, цветов и логики размещения задач

### Типы

- **`gantt.types.ts`** - TypeScript интерфейсы для всех компонентов диаграммы

## Преимущества новой структуры

1. **Читаемость** - Каждый компонент отвечает за одну конкретную задачу
2. **Переиспользование** - Компоненты можно использовать в других частях приложения
3. **Тестируемость** - Каждый компонент можно тестировать отдельно
4. **Поддерживаемость** - Легче находить и исправлять ошибки
5. **Разделение ответственности** - Логика разделена по соответствующим компонентам

## Использование

```tsx
import GanttChart from '@/components/charts/GanttChart';

// В компоненте
<GanttChart selectedWeek={new Date()} />
```

## Основные функции

- Отображение задач по пользователям отдела
- Цветовая индикация статуса задач
- Автоматическое размещение пересекающихся задач на разных уровнях
- **Автоматическая адаптивная ширина** - диаграмма автоматически занимает всю доступную ширину родительского контейнера
- **Детальная временная шкала** - отображение чисел месяца над днями недели для лучшей ориентации
- Динамическая высота в зависимости от количества пользователей и задач
- Интерактивные полосы задач с модальными окнами
- Поддержка темной темы
- Responsive дизайн с автоматическим масштабированием
