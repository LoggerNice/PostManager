# Диаграмма Ганта проектов

Компонентная диаграмма Ганта для отображения проектов на временной шкале.

## 🚀 Возможности

- **Отображение проектов** - каждый проект отображается как полоса на временной шкале с информацией о ГК и сроках выполнения (год в сокращенном формате)
- **6-месячный обзор** - показывает ближайшие 6 месяцев с текущего месяца (без отображения года)
- **Ограничение длины** - проекты автоматически обрезаются до последнего отображаемого месяца (6 месяцев)
- **Цветовая индикация** - разные цвета для разных статусов проектов
- **Адаптивный дизайн** - автоматически подстраивается под размер контейнера без прокрутки
- **Интерактивность** - клик по проекту для получения дополнительной информации
- **Индикация обрезания** - визуальное предупреждение о проектах, обрезанных до 6 месяцев

## Структура компонентов

### Основные компоненты

- **`ProjectGanttChart.tsx`** - Главный компонент диаграммы, объединяющий все остальные
- **`TimelineHeader.tsx`** - Заголовок временной шкалы с названиями месяцев и числами
- **`ProjectRow.tsx`** - Строка проекта с информацией и полосой
- **`ProjectBar.tsx`** - Полоса проекта с прогрессом и статусом

### Вспомогательные файлы

- **`useProjectGanttData.ts`** - Хук для получения и обработки данных проектов
- **`projectGanttUtils.ts`** - Утилиты для расчета позиций и форматирования
- **`projectGantt.types.ts`** - TypeScript интерфейсы

## Использование

```tsx
import ProjectGanttChart from '@/components/charts/projectGantt/ProjectGanttChart';

// В компоненте
<ProjectGanttChart 
  onProjectClick={(project) => console.log('Clicked:', project)}
  className="w-full"
/>
```

## Статусы проектов

- **Активные** (синий) - проекты в процессе выполнения
- **Завершенные** (зеленый) - проекты с истекшим сроком
- **Просроченные** (красный) - проекты с просроченным сроком
- **Предстоящие** (серый) - проекты, которые еще не начались
