# Админ панель PostManager

## Описание
Админ панель предоставляет системным администраторам полный контроль над приложением PostManager.

## Функциональность

### 1. Dashboard (Дашборд)
- Общая статистика системы
- Количество пользователей, проектов, задач и отделов
- Статистика выполнения задач
- Информация о загрузке системы

### 2. Управление пользователями
- Просмотр всех пользователей системы
- Создание новых пользователей
- Редактирование существующих пользователей
- Удаление пользователей
- Назначение ролей и отделов
- Поиск пользователей

### 3. Управление отделами
- Просмотр всех отделов
- Создание новых отделов
- Редактирование названий отделов
- Удаление отделов
- Просмотр статистики по отделам

### 4. Системные настройки
- Режим технического обслуживания
- Настройки регистрации пользователей
- Роль по умолчанию
- Время сессии
- Настройки файлов (размер, типы)
- Создание резервных копий
- Очистка кэша

### 5. Системные логи
- Просмотр всех системных логов
- Фильтрация по уровню (INFO, WARN, ERROR)
- Автообновление логов
- Пагинация

## Доступ
Админ панель доступна пользователям с ролями `ADMIN` и `MANAGER` по адресу `/admin`.

## Безопасность
- Middleware проверяет роль пользователя
- Все API endpoints защищены на уровне сервера
- Автоматический редирект неавторизованных пользователей

## Компоненты
- `AdminPanel.tsx` - основной компонент с навигацией
- `AdminStats.tsx` - дашборд со статистикой
- `UserManagement.tsx` - управление пользователями
- `DepartmentManagement.tsx` - управление отделами
- `SystemSettings.tsx` - системные настройки
- `SystemLogs.tsx` - просмотр логов

## API Endpoints
Все админские API endpoints находятся в `src/store/api/admin.api.ts` и используют префикс `/admin/`.
