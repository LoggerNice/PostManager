# Система уведомлений для исполнителей задач

## Обзор

Система уведомлений обеспечивает автоматическое информирование всех исполнителей задачи о различных событиях, связанных с их задачами. Уведомления включают как визуальные toast-сообщения, так и звуковое сопровождение.

## Компоненты системы

### 1. Хуки уведомлений

#### `useTaskNotifications` (`src/hooks/useTaskNotifications.ts`)
Основной хук для отслеживания изменений задач и показа уведомлений.

**Функциональность:**
- Отслеживание новых задач
- Отслеживание обновлений задач (статус, приоритет, дедлайн, исполнители)
- Отслеживание удаления задач
- Автоматическое воспроизведение звуков
- Показ toast-уведомлений

#### `useTaskAssigneeNotifications` (`src/hooks/useTaskAssigneeNotifications.ts`)
Дополнительный хук с расширенной функциональностью для уведомлений исполнителей.

**Функциональность:**
- Более детальное отслеживание изменений
- Возврат функций для внешнего использования
- Оптимизированная производительность с useCallback

### 2. Типы уведомлений

#### Новые задачи
- **Триггер:** Создание новой задачи
- **Получатели:** Все назначенные исполнители
- **Сообщение:** "Вам назначена новая задача: [название]"
- **Звук:** `/meet-message-sound-1.mp3`
- **Иконка:** 📋

#### Выполнение задач
- **Триггер:** Перемещение задачи в статус "Выполнено"
- **Получатели:** Все исполнители задачи
- **Сообщение:** "Задача [название] выполнена! 🎉"
- **Звук:** `/cena_notification.mp3`
- **Иконка:** ✅

#### Обновление задач
- **Триггер:** Изменение статуса, приоритета, дедлайна или исполнителей
- **Получатели:** Все исполнители задачи
- **Сообщение:** Зависит от типа изменения (без указания конкретных исполнителей)
- **Звук:** `/meet-message-sound-1.mp3`
- **Иконка:** 📝

#### Удаление задач
- **Триггер:** Удаление задачи
- **Получатели:** Все исполнители задачи
- **Сообщение:** "Задача [название] была удалена"
- **Звук:** Нет
- **Иконка:** 🗑️

## Интеграция в проект

### Использование в компонентах

```tsx
import { useTaskNotifications } from '@/hooks/useTaskNotifications';

function ProjectPage() {
  const { data: tasks, isLoading } = useGetProjectTasksQuery(projectId);
  
  // Хук для уведомлений (только один для избежания дублирования)
  useTaskNotifications({
    tasks: tasks || [],
    isLoading,
    projectId
  });
  
  // ... остальной код
}
```

### Автоматические уведомления

Система автоматически отслеживает следующие события:

1. **Создание задач** - уведомления отправляются всем исполнителям
2. **Перемещение задач** - уведомления о изменении статуса
3. **Обновление задач** - уведомления о изменении приоритета, дедлайна
4. **Изменение исполнителей** - уведомления о добавлении/удалении исполнителей
5. **Удаление задач** - уведомления всем исполнителям

## Звуковые уведомления

### Файлы звуков
- `/meet-message-sound-1.mp3` - для новых задач и обновлений
- `/cena_notification.mp3` - для выполненных задач

### Настройка звука
```tsx
const playNotificationSound = (soundType: 'task-created' | 'task-completed' | 'task-updated') => {
  try {
    let audioFile = '/meet-message-sound-1.mp3';
    
    if (soundType === 'task-completed') {
      audioFile = '/cena_notification.mp3';
    }
    
    const audio = new Audio(audioFile);
    audio.volume = 0.5;
    audio.play().catch(error => {
      console.log(`Не удалось воспроизвести звук:`, error);
    });
  } catch (error) {
    console.log(`Ошибка при создании аудио элемента:`, error);
  }
};
```

## Настройка уведомлений

### Параметры toast-уведомлений

```tsx
toast.success(message, {
  duration: 8000, // Длительность показа (мс)
  icon: '📋', // Иконка уведомления
  style: {
    background: '#10b981', // Цвет фона
    color: '#ffffff', // Цвет текста
    fontSize: '14px', // Размер шрифта
    fontWeight: '500' // Толщина шрифта
  }
});
```

### Цветовая схема
- **Зеленый** (`#10b981`) - новые задачи, выполненные задачи
- **Синий** (`#3b82f6`) - обновления задач
- **Красный** (`#ef4444`) - удаление задач

## Производительность

### Оптимизации
1. **useCallback** - для предотвращения лишних ререндеров
2. **useRef** - для хранения предыдущего состояния
3. **Пропуск первой загрузки** - избежание ложных уведомлений
4. **Проверка исполнителей** - уведомления только для исполнителей задачи
5. **Защита от дублирования** - предотвращение повторных уведомлений в течение 2 секунд

### Мониторинг
```tsx
// Логирование для отладки
console.log(`Уведомляем исполнителей о новой задаче: ${assigneeIds.join(', ')}`);
console.log(`Уведомляем исполнителей о перемещении задачи: ${assigneeNames.join(', ')}`);
```

## Безопасность

### Проверки
- Проверка авторизации пользователя
- Проверка ролей и прав доступа
- Валидация данных задач
- Обработка ошибок воспроизведения звука

### Обработка ошибок
```tsx
try {
  const audio = new Audio(audioFile);
  audio.volume = 0.5;
  audio.play().catch(error => {
    console.log('Не удалось воспроизвести звук:', error);
  });
} catch (error) {
  console.log('Ошибка при создании аудио элемента:', error);
}
```

### Исправление типов данных
Система корректно обрабатывает различные форматы дат:
```tsx
// Безопасное сравнение дат
const prevDeadline = prevTask.deadline ? new Date(prevTask.deadline).getTime() : null;
const currentDeadline = task.deadline ? new Date(task.deadline).getTime() : null;

if (prevDeadline !== currentDeadline) {
  // Обработка изменения дедлайна
}
```

### Интеграция с WebSocket
Для real-time уведомлений можно интегрировать WebSocket:
```tsx
// Пример интеграции с WebSocket
useEffect(() => {
  const ws = new WebSocket('ws://localhost:3045/notifications');
  
  ws.onmessage = (event) => {
    const notification = JSON.parse(event.data);
    showNotification(notification);
  };
  
  return () => ws.close();
}, []);
```
