# Система ролей при регистрации

## Обзор

В PostManager добавлена возможность выбора роли пользователя при регистрации. Система поддерживает три основные роли с различными уровнями доступа.

## Доступные роли

### 👑 Администратор (ADMIN)
**Описание**: Полный доступ ко всем функциям системы

**Возможности**:
- Управление пользователями и ролями
- Создание и удаление проектов
- Управление отделами
- Доступ к системной аналитике
- Настройка системы

### 👨‍💼 Менеджер (MANAGER)
**Описание**: Управление проектами и командой

**Возможности**:
- Создание и редактирование проектов
- Назначение задач участникам
- Просмотр отчетов по проектам
- Управление участниками проектов

### 👤 Пользователь (USER)
**Описание**: Участие в проектах и выполнение задач

**Возможности**:
- Просмотр назначенных проектов
- Выполнение и обновление задач
- Комментирование задач
- Просмотр календаря проектов

## Компоненты системы

### 1. Форма регистрации
- **Файл**: `postmanager-frontend/src/app/auth/Auth.tsx`
- **Функциональность**: Выбор роли из выпадающего списка
- **Валидация**: Обязательное поле при регистрации

### 2. Информация о ролях
- **Файл**: `postmanager-frontend/src/components/auth/RoleInfo.tsx`
- **Функциональность**: Динамическое отображение описания выбранной роли
- **UX**: Раскрывающаяся информация с детальными возможностями

### 3. Индикатор надежности пароля
- **Файл**: `postmanager-frontend/src/components/auth/PasswordStrength.tsx`
- **Функциональность**: Визуальная оценка надежности пароля в реальном времени
- **Критерии**: Длина, цифры, заглавные и строчные буквы

## Использование

### Регистрация нового пользователя

1. Пользователь заполняет форму регистрации
2. Выбирает роль из выпадающего списка
3. Система отображает информацию о выбранной роли
4. При вводе пароля показывается индикатор надежности
5. После успешной регистрации пользователь получает выбранную роль

### Пример API запроса регистрации

```typescript
const registerData: IRegisterData = {
  name: "Иван Иванов",
  login: "ivan.ivanov",
  password: "SecurePass123",
  departmentId: 1,
  role: "MANAGER"
};

const response = await register(registerData).unwrap();
```

## Валидация

### Клиентская валидация
- **Роль**: Обязательное поле
- **Пароль**: Минимум 6 символов с проверкой надежности
- **Подтверждение пароля**: Должно совпадать с основным паролем

### Серверная валидация
- Проверка существования выбранной роли
- Валидация прав доступа
- Проверка уникальности логина
